# Digital Marketing — Agency Landing Page

A modern, fully responsive digital marketing agency website built with a clean, professional aesthetic and a focus on smooth animations and intuitive navigation. The site presents agency services, case studies, and pricing plans across five dedicated pages.

## ✨ Features

### 🏠 Home
- **Hero section** with a bold headline and a clear call-to-action leading to the Services page.
- **Services preview** — four service cards with SVG icons showcasing core offerings.
- **About Us snapshot** with agency mission and values.
- **Pricing plans** — monthly / yearly toggle with three tier cards (Basic, Standard, Premium).
- **Why Choose Us** — animated count-up stats for completed projects and specialized employees.
- **Brand partners** — auto-scrolling logo strip with trusted client brands.
- **Case Study preview** — three portfolio cards linking to the full case study page.
- **Testimonial** — client quote with name and title.
- **CTA banner** — prominent contact invitation at the bottom of every page.

### 📄 Pages
- **About** — full agency story, mission statement, stats section, and brand partners.
- **Services** — detailed four-card services grid and complete pricing plan table.
- **Case Study** — full project portfolio gallery (3 showcases) with a featured testimonial.
- **Contact** — contact form with name / email / message fields, plus address, phone, and email info blocks.

### 🎨 Design
- Clean, professional light theme with a bold color accent.
- Fully responsive layout — desktop multi-column, tablet, and single-column mobile with a hamburger nav.
- Scroll-triggered entrance animations throughout all sections.
- Smooth section transitions and hover effects on cards and buttons.
- Consistent header and footer navigation across all pages.

## 🛠 Tech Stack
- **HTML5** — semantic, multi-page structure
- **CSS3** — custom styles with scroll animations and transitions
- **Bootstrap** — responsive grid system and UI components
- **JavaScript** — pricing toggle, animated count-up counters, and interactive behaviors

## 🚀 Getting Started

No build tools or dependencies required — just open in a browser.

```bash
# 1. Clone the repository
git clone https://github.com/Abdelrouaf/Digital-Marketing.git

# 2. Open in your browser
open index.html
```

Or simply download the ZIP and open `index.html` with any browser.
